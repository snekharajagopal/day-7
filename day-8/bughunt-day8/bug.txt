Bug 1
{ name: "Book", price: 120, qty: 2 }
{ name: "Bag", price: 750, qty: 1 },

{ name: "Book", price: 120, qty: 2 },
{ name: "Bag", price: 750, qty: 1 },

Bug 6

    item.name;
});

Bug 7:
const costly = cart.filter(item => item.price = 100);
here it should check whether one value is greater that other.

correct fix
const costly = cart.filter(item => item.price > 100);


Bug 8
const sum = cart.reduce((s, item) => s + item.price);
it does not give initial value because pricce only adds, not mutliply by quantity.

correct fix:
const sum = cart.reduce(
    (s, item) => s + item.price * item.qty,
    0
);


Bug 9
const sorted = cart.sort((a, b) => a.price > b.price);
   it should return negative or zero or positive number.

correct fix:
const sorted = [...cart].sort((a, b) => a.price - b.price);

Bug 1.

Bug 3. 
Adding 5 gives a strange answer.
let age = prompt("Your age?");   // user types 20
console.log(age + 5);

Bug:  prompt returns string. so if we add string with number, it just join or concatenates, it will not do addition operation. 
      so we have to change the string into number ()
correct code:
let age = Number(prompt("Your age?"));
console.log(age + 5);

{ console.log(i); }
 
Bug: for (let i = 1; i <= 3; i++); , in this line there is semicolon; at the end, the syntax is wrong , loops does not have ;.
     The semicolon after the for loop ends the loop immediately.then i is not available.
correct code:
for (let i = 1; i <= 3; i++) {
  console.log(i);
}



Bug 5.
The browser tab freezes.
let n = 5;
while (n > 0) { console.log(n); }

Bug: The loop never changes n, so its condition remains true forever and it creates infinite loop.
correct code: 
let n = 5;

while (n > 0) {
  console.log(n);
  n--;
}



Bug 6. 
Tuesday is printed together with Monday.
let day = 1;
switch (day) {
  case 1: console.log("Monday");
  case 2: console.log("Tuesday");
}

Bug:  Missing break after case 1 so it also go  into case 2.
correct code :
let day = 1;

switch (day) {
  case 1:
    console.log("Monday");
    break;
  case 2:
    console.log("Tuesday");
    break;
}
